# data — 노트북에서 불러 쓰는 수업 자료

선생님이 코랩 노트북과 함께 주신 csv, 이미지, 텍스트 파일을 이 폴더에 그대로 올립니다.

## 동작 방식

- INFSUB가 파이썬 환경을 시작할 때 이 폴더의 모든 파일을 **파이썬 가상 디스크의 `/content` 안에 복사**합니다.
- `/content` 는 코랩의 기본 작업 폴더라, 노트북 코드를 고치지 않아도 그대로 열립니다.

```python
cv2.imread('/content/bad_dog.png')   # 됩니다
cv2.imread('bad_dog.png')            # 됩니다 (작업 폴더가 /content)
pd.read_csv('/content/scores.csv')   # 됩니다
```

- `google.colab` 은 실제로는 없지만 흉내 낸 모듈이 등록돼 있습니다.
  - `drive.mount(...)` — 아무 일도 하지 않고 안내 문구만 출력합니다.
  - `cv2_imshow(...)` — 코랩과 같은 규칙(BGR 순서, 0~255 클립)으로 이미지를 표시합니다.
  - `files.upload()` / `files.download()` — 안내 문구만 출력합니다.

## 올릴 때 규칙

1. **폴더를 만들지 말고 파일만 평평하게** 올립니다. 하위 폴더는 복사되지 않습니다.
2. **파일 이름은 노트북 코드에 적힌 그대로**여야 합니다. 대소문자와 확장자까지 같아야 합니다.
3. 한글 파일 이름도 되지만, 노트북 코드와 글자가 정확히 같아야 합니다.
4. 용량이 큰 파일은 피합니다. 학생이 파이썬을 켤 때마다 전부 내려받으므로, 합쳐서 몇 MB 안쪽을 권장합니다.
5. 파일 목록은 브라우저에 10분간 캐시됩니다. 방금 올린 파일이 안 보이면 새로고침하거나 잠시 기다립니다.
