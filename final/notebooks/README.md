# 기말고사 노트북

선생님이 올려 주신 코랩 파일(`.ipynb`)을 이 폴더에 올립니다.

- GitHub 웹에서 이 폴더로 들어와 **Add file → Upload files** 로 올리고 `main` 에 커밋합니다.
- 사이드바에서 **기말고사**를 고르면 노트북 목록에 나타납니다.
- 파일 이름이 목록에 보이는 이름이 됩니다. 순서를 맞추려면 앞에 번호를 붙입니다 (예: `6_머신러닝기초.ipynb`).
- 노트북이 불러 쓰는 csv·이미지 파일은 공용 `data/` 폴더에 올립니다.
- 문항 은행의 `src` 값은 이 폴더의 파일 이름(확장자 제외)과 같아야 합니다.

이 README 파일은 빈 폴더를 깃허브에 남기려고 둔 것이며, 사이트 목록에는 나오지 않습니다.
