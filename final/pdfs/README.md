# 기말고사 PDF 자료

수업 PDF 파일(`.pdf`)을 이 폴더에 올립니다.

- GitHub 웹에서 이 폴더로 들어와 **Add file → Upload files** 로 올리고 `main` 에 커밋합니다.
- 사이드바에서 **기말고사**를 고르면 PDF 자료실과 PDF 퀴즈에 나타납니다.
- PDF 퀴즈 문항(`bank/question-bank-pdf.json`)의 `src` 값은 이 폴더의 파일 이름(확장자 제외)과 같아야 합니다.
- 작성 규칙과 기출 자료 취급 방법은 `midterm/pdfs/README.md` 를 참고합니다.

이 README 파일은 빈 폴더를 깃허브에 남기려고 둔 것이며, 사이트 목록에는 나오지 않습니다.
