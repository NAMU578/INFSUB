# PDF 자료실

이 폴더에 `.pdf` 파일을 올리면 사이트의 "PDF 자료실" 메뉴에 자동으로 나타납니다.

## 사용법
1. GitHub 웹에서 이 폴더(`pdfs/`)로 들어와 **Add file → Upload files**로 PDF를 올립니다.
2. `main` 브랜치에 커밋하면 몇 분 안에 학생 화면에 반영됩니다 (GitHub Pages 배포 지연 포함).
3. 파일 이름이 곧 목록에 표시되는 이름입니다 (확장자 `.pdf` 제외). 필요하면 순서를 위해 앞에 번호를 붙이세요 (예: `1_전자기유도.pdf`).

## 참고
- 학생은 PDF 안의 텍스트를 드래그로 선택해 AI에게 질문할 수 있습니다 (노트북 채팅과 동일한 방식/저장소).
- 스캔본처럼 텍스트 레이어가 없는 PDF는 이미지로는 보이지만 텍스트 선택은 되지 않습니다.
