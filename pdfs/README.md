# PDF 자료실

이 폴더에 `.pdf` 파일을 올리면 사이트의 "PDF 자료실" 메뉴에 자동으로 나타납니다.

## 사용법
1. GitHub 웹에서 이 폴더(`pdfs/`)로 들어와 **Add file → Upload files**로 PDF를 올립니다.
2. `main` 브랜치에 커밋하면 몇 분 안에 학생 화면에 반영됩니다 (GitHub Pages 배포 지연 포함).
3. 파일 이름이 곧 목록에 표시되는 이름입니다 (확장자 `.pdf` 제외). 필요하면 순서를 위해 앞에 번호를 붙이세요 (예: `1_전자기유도.pdf`).

## 참고
- 학생은 PDF 안의 텍스트를 드래그로 선택해 AI에게 질문할 수 있습니다 (노트북 채팅과 동일한 방식/저장소).
- 스캔본처럼 텍스트 레이어가 없는 PDF는 이미지로는 보이지만 텍스트 선택은 되지 않습니다.

## PDF 퀴즈와 연결하기
- 사이드바의 **PDF 퀴즈** 메뉴는 `bank/question-bank-pdf.json` 에 들어 있는 문항만 사용합니다.
- 문항의 `src` 값이 이 폴더의 **파일 이름(확장자 제외)** 과 같아야 그 자료의 문제로 인식됩니다.
  예) `pdfs/06.인공지능의 역사.pdf` → `"src": "06.인공지능의 역사"`
- 문항이 하나도 없는 PDF는 PDF 퀴즈 목록에 나타나지 않습니다 (자료실에서는 그대로 보입니다).
- 파일 이름을 바꾸면 문항 연결이 끊어지므로, 이름을 바꿀 때는 `src` 값도 함께 고쳐야 합니다.

## 기출 자료 취급
- `기출_넘파이모듈관련.pdf` 에는 **전재·복제 금지** 문구가 들어 있습니다.
- 따라서 문제은행에는 기출 문항을 옮겨 담지 않았습니다. **출제 주제와 유형만 참고해 문항을 새로 작성**했습니다.
  (코드·보기·수치를 그대로 가져온 문항은 없습니다.)
- 기출 대비 문항의 정답은 numpy 로 실제 실행해 검증했습니다. `verifyCode` / `verifyExpect` 필드에 검증용 코드가 들어 있습니다.
- `CONFIG.BANK_VERIFY` 를 `true` 로 두면 출제 직전에 브라우저에서 한 번 더 실행해 확인합니다 (시작이 몇 초 느려집니다).
